# TrenoNote

Дневник пауэрлифтера в браузере: план тренера (текстом или из Excel), отметки подходов,
таймер отдыха, разминки с видео, заметки, калькулятор блинов, траектория грифа на видео.
Работает без интернета: после первого открытия всё хранится на телефоне.

## Установка на iPhone
1. Откройте ссылку на приложение в **Safari**.
2. Нажмите «Поделиться» → **«На экран „Домой“»**.
3. Запускайте с иконки «TrenoNote».

## Установка на Android
Откройте ссылку в Chrome → меню ⋮ → «Установить приложение».

Данные (планы, отметки, заметки, видео разминок) хранятся только на вашем устройстве.
